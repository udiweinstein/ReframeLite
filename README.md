# Reframe Lite (Android)

גרסה רזה לאנדרואיד של עורך ה-360: תמיד בפורמט עומד 9:16.

## מה יש
- פתיחה של קבצי GoPro MAX ‏(‎.360‎), ‏Insta360 ‏(‎.insv‎) ווידאו 360 ‏(equirectangular).
- ‏Reframe: גוררים באצבע כדי להסתובב, וצובטים לזום.
- ‏⟦ Start ו-End ⟧: מסמנים את התחלת הקטע וסופו במיקום הנוכחי. לחיצה ארוכה מאפסת את הסימון.
- ‏◎ Track ‏(Deep Track): עוצרים, לוחצים ומסמנים ריבוע סביב האובייקט. המצלמה עוקבת אחריו מהנקודה הזו ועד סוף הקטע. לחיצה ארוכה מוחקת את המעקב.
- ‏Export: וידאו ‎1080×1920‎ ‏(H.264) עם השמע המקורי, שנשמר ב-Movies/Reframe.

## בנייה
- **‏GitHub:** כל push ל-main בונה APK ומפרסם אותו ב-Releases, ומשם מורידים אותו מהטלפון.
- **‏Android Studio:** פותחים את התיקייה ולוחצים Run.

## הערות
- התצוגה המקדימה בלי סאונד. הייצוא כולל את השמע.
- ‏Deep Track עובד עם template matching על-המכשיר, בלי ספריות חיצוניות.
